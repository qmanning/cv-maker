# IcedCoffee brand files

- `icedcoffee-glyph.svg` — the mark on its own (black). Two overlapping sheets with the overlap filled: a version, and the next one.
- `icedcoffee-icon.svg` — the mark in white on IcedCoffee blue `#004DFF`, full-bleed square. Favicons, avatars, anywhere a tile is wanted.

Both are Q Manning's originals and are the source of truth. Derived from them, never edited by hand:
`electron/build/icon.svg` (the macOS / Windows app icon: the same tile on Apple's 824-in-1024 rounded-square grid) and the
inline `currentColor` copies in the desktop app's welcome and Connect windows.
