Connect your AI

Use the AI app you already have. It reads the résumé that's open here and changes it while you watch. No API key, no account, nothing to pay CV Maker.

Claude Desktop

  1. Quit Claude and open it again so it notices CV Maker.
  2. In a Claude chat, ask: “Tailor my résumé to this job description” and paste it in. Claude will ask permission to use CV Maker the first time.
  3. Watch the page here. Every change comes with an Undo.
ChatGPT desktop app & Codex

  1. Quit and reopen the ChatGPT app (or start a new Codex session).
  2. Ask it: “Use CV Maker to tighten my résumé to one page.”
Claude Code, Cursor, VS Code, LM Studio…

Any app that supports MCP servers can connect. Paste this into its MCP settings, or run the Claude Code command.

Advanced: type requests inside CV Maker with an API key

This adds a prompt bar under the page. It needs a pay-as-you-go API key, or a model running on this computer.

Where your key goes: it is encrypted by your computer's keychain and kept on this computer. When you ask for a change, CV Maker sends your request and the résumé's text directly to the provider you chose above, and nowhere else. Nothing goes to qmanning.com. With a model on this computer, nothing leaves it at all.
